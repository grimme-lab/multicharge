= multicharge(1)

== Name
multicharge - Atomic partial charge model.


== Synopsis
*multicharge* [_options_] _input_


== Description
Electronegativity equilibration model for atomic partial charges.
Supports molecular (0D) and periodic systems in 1D (wires), 2D (slabs), and 3D (crystals).
For 1D and 2D periodic systems, the standard EEQ model uses exact 1D/2D Ewald summation and requires a neutral unit cell (`--charge 0`), whereas the EEQBC model uses screened direct-space lattice summation and supports both neutral and charged periodic unit cells.


== Options

*-m, -model, --model* _model_::
Choose the charge model (eeq or eeqbc)

*-i, -input, --input* _format_::
Hint for the format of the input file

*-c, -charge, --charge* _value_::
Provide the molecular charge

*-g, -grad, --grad*::
Evaluate molecular gradient and virial

*-j, -json, --json*::
Provide output in JSON format to the file 'multicharge.json'

*-v, -version, --version*::
Print program version and exit

*-h, -help, --help*::
Show this help message
